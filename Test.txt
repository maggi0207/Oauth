thorough code review of the Active IP Search implementation
across the FACTS API and Formulation API repositories.

CONTEXT
-------
We have two repositories:

1. FACTS API
2. Formulation API

We have implemented a new Active IP Search feature
across both repositories.

The Formulation API exposes the search endpoint.
The FACTS API consumes that endpoint and exposes
its own search endpoint to the Angular UI.

However, we need to verify that our implementation
follows the existing repository architecture and
coding patterns.

PRIMARY OBJECTIVE
-----------------
Inspect existing FACTS API endpoints that communicate
with Formulation API.

Use those existing implementations as the reference
for reviewing our new Active IP Search implementation.

Do not assume our current implementation is correct.

PHASE 4: VERIFY SEARCH LOGIC
----------------------------

Check whether the search implementation meets
the following requirements:

1. Search by Input Active.
2. Search by Output Active.
3. Support searching with either field empty.
4. When both fields are provided, apply AND logic.
5. Support partial matching.
6. Filter input and output using the correct Side values.
7. Return distinct Active IP records.
8. Sort results by Chemical Equation.
9. Handle null, empty, and whitespace-only inputs.
10. Return the correct response when no records match.

Verify that the implementation handles these cases
correctly in both repositories.
